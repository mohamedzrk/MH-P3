# Práctica 4: Enfriamiento Simulado y Búsqueda Tabú (Planificación de Exámenes)

## Requisitos
Instalar las dependencias necesarias:
```bash
pip install -r requirements.txt
```

## Ejecución
Para lanzar todos los algoritmos y generar las métricas de la memoria, ejecutar la siguiente orden:
```bash
python experimentos_p4.py
```
